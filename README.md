# Burda Finance

Веб-приложение семейных финансов с телефона: https://yb471.github.io/cash/
Раздел Cash YB — учёт расходов и приходов наличными и их сверка.

Страница без секретов: данные уходят в функцию Supabase по коду доступа, который вводится один раз на телефоне.
Устанавливается на экран «Домой» (Safari → Поделиться → На экран «Домой»).
